# Bloque 3a — Photos Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Image attachments show inline in the feed, thread and exam roster; photos are shrunk on the phone before upload; everyone can set (and the teacher can remove) their own profile photo.

**Architecture:** The backend adds a one-hour signed R2 link to every displayable image attachment and to every user's avatar, through two helpers in a new `app/services/media.py`. The frontend renders attachments with a new `PostPhotos` component and full-screen viewer, shrinks photos in the browser in a new `src/lib/images.ts` before they reach any upload, and gets a small `/perfil` page to change the photo and bio.

**Tech Stack:** FastAPI + SQLAlchemy + Alembic + pytest; React + Vite + TanStack Query + vitest; shadcn `base-sera` on `@base-ui/react`; `@remixicon/react`; Cloudflare R2 via boto3 (`app/storage.py`).

**Spec:** `docs/superpowers/specs/2026-10-19-fotos-design.md` — read it before starting.

**Spec amendment (made while planning, flagged to Mario):** the spec puts the profile-photo controls on `/onboarding`. That page redirects anyone who already has a username to `/` (`Onboarding.tsx` first `useEffect`), so existing students could never reach them — nor edit their bio today. Task 5 adds a small `/perfil` page (photo + bio) and points the bottom-nav "Perfil" icon there. `/onboarding` stays the first-login page. The profile page `/u/:username` (next spec) will absorb `/perfil` later.

## Global Constraints

- Shrink once, keep no original: **2048 px on the long side**, JPEG quality **0.85**, never enlarge. Profile photo: centre square, **512 px**.
- A HEIC is always delivered converted (even if larger); a JPEG/PNG/WebP whose "shrunk" result is larger keeps the original. GIF and SVG are never re-encoded.
- Displayable attachment types (`url` set): `image/jpeg`, `image/png`, `image/webp`, `image/gif`. Everything else: `url = None`, rendered as a chip.
- Signed links are valid **one hour** (`storage.generate_presigned_url(key, expires=3600)`); no R2 configured → `url = None` / Google avatar.
- Deleted post → no attachments (unchanged). Vetoed post → keeps its photos.
- Server never trusts the client: post uploads keep the 10 MB cap and allowed extensions. Avatar upload: `image/jpeg`, `image/png`, `image/webp` only, ≤ 10 MB, else 422; no R2 → 400.
- Teacher removes an avatar only for a user enrolled in a class they teach; otherwise 403.
- All user-facing text in `frontend/src/strings/es.ts` (Spanish placeholders; Mario writes final copy). Icons only from `@remixicon/react`; no emojis as UI. Use preset components (`@/components/ui/*`) unmodified; add missing ones with `npx shadcn add <name>`; never hand-roll `<input className="border …">`.
- One control per line in any form.
- `src/lib` modules with a `*.test.ts` use relative imports only (vitest doesn't resolve `@/`).
- Tests never talk to Cloudflare: monkeypatch `storage.is_r2_configured`, `storage.upload_bytes`, `storage.generate_presigned_url`.
- Backend tests: `cd backend && .venv/bin/python -m pytest -q`. Frontend: `cd frontend && npx tsc -b --noEmit && npx eslint src && npm test && npm run build` (one pre-existing eslint warning in `src/components/ui/button.tsx` — leave it).

```python
from app import storage
from app.models import Attachment
from app.schemas import AttachmentOut

# What a browser can show in an <img> on any phone. HEIC (Android can't) and
# SVG stay chips; so does everything that isn't an image.
DISPLAYABLE = {"image/jpeg", "image/png", "image/webp", "image/gif"}

LINK_SECONDS = 3600


def attachment_out(att: Attachment) -> AttachmentOut:
    """An attachment as the API sends it. Displayable images carry a signed
    R2 link valid for an hour; signing is local, so a page of posts costs no
    network calls."""
    url = None
    if att.mime_type in DISPLAYABLE and storage.is_r2_configured():
        url = storage.generate_presigned_url(att.file_key, expires=LINK_SECONDS)
    return AttachmentOut(id=att.id, file_name=att.file_name,
                         mime_type=att.mime_type, url=url)
```

```ts
import type { Attachment } from "./types";

/** One photo gets a fixed 4:5 box (whole photo visible, no jump while
 *  loading); two to four get a two-column grid of square tiles. */
export function photoLayout(n: number): "single" | "grid" | "none" {
  if (n <= 0) return "none";
  return n === 1 ? "single" : "grid";
}

/** The server decides what is displayable by sending a url. A HEIC or a PDF
 *  arrives with url = null and stays a chip. */
export function splitAttachments(atts: Attachment[]) {
  return {
    photos: atts.filter((a) => a.url),
    files: atts.filter((a) => !a.url),
  };
}
```

```tsx
import { useState } from "react";
import { RiArrowLeftSLine, RiArrowRightSLine, RiAttachment2 } from "@remixicon/react";
import { api } from "@/lib/api";
import { photoLayout, splitAttachments } from "@/lib/photos";
import { Button } from "@/components/ui/button";
import { Dialog, DialogContent, DialogTitle } from "@/components/ui/dialog";
import { es } from "@/strings/es";
import type { Attachment, Author } from "@/lib/types";

/** A photo whose signed link expired (tab open over an hour) asks for a
 *  fresh one once, then gives up quietly. */
function Photo({ att, alt, className }: { att: Attachment; alt: string; className: string }) {
  const [src, setSrc] = useState(att.url ?? "");
  const [retried, setRetried] = useState(false);
  return (
    <img
      src={src}
      alt={alt}
      loading="lazy"
      decoding="async"
      className={className}
      onError={async () => {
        if (retried) return;
        setRetried(true);
        try {
          const { url } = await api<{ url: string }>(`/api/attachments/${att.id}/url`);
          setSrc(url);
        } catch {
          /* leave the grey box */
        }
      }}
    />
  );
}

export default function PostPhotos({
  attachments,
  author,
  onOpenFile,
}: {
  attachments: Attachment[];
  author: Author;
  onOpenFile?: (id: number) => void;
}) {
  const { photos, files } = splitAttachments(attachments);
  const [open, setOpen] = useState<number | null>(null);
  const alt = es.attachments.photoAlt.replace("{user}", author.username ?? author.name);
  const layout = photoLayout(photos.length);

  return (
    <div className="mt-2 flex flex-col gap-2">
      {layout === "single" && (
        <button type="button" onClick={() => setOpen(0)} className="block w-full">
          <div className="aspect-[4/5] w-full bg-muted">
            <Photo att={photos[0]} alt={alt} className="size-full object-contain" />
          </div>
        </button>
      )}
      {layout === "grid" && (
        <div className="grid grid-cols-2 gap-1">
          {photos.map((p, i) => (
            <button key={p.id} type="button" onClick={() => setOpen(i)} className="block">
              <div className="aspect-square bg-muted">
                <Photo att={p} alt={alt} className="size-full object-cover" />
              </div>
            </button>
          ))}
        </div>
      )}
      {files.length > 0 && (
        <div className="flex flex-wrap gap-2">
          {files.map((a) =>
            onOpenFile ? (
              <button
                key={a.id}
                onClick={() => onOpenFile(a.id)}
                className="inline-flex max-w-full items-center gap-1 border px-2 py-1 text-xs"
              >
                <RiAttachment2 className="size-3 shrink-0" />
                <span className="truncate">{a.file_name}</span>
              </button>
            ) : (
              <span key={a.id} className="inline-flex items-center gap-1 border px-2 py-1 text-xs">
                <RiAttachment2 className="size-3" /> {a.file_name}
              </span>
            ),
          )}
        </div>
      )}

      <Dialog open={open != null} onOpenChange={(o) => !o && setOpen(null)}>
        <DialogContent>
          <DialogTitle className="sr-only">{alt}</DialogTitle>
          {open != null && (
            <Photo att={photos[open]} alt={alt} className="max-h-[80dvh] w-full object-contain" />
          )}
          {photos.length > 1 && open != null && (
            <div className="flex justify-between">
              <Button variant="ghost" size="icon-sm" aria-label={es.attachments.previous}
                      disabled={open === 0} onClick={() => setOpen(open - 1)}>
                <RiArrowLeftSLine />
              </Button>
              <Button variant="ghost" size="icon-sm" aria-label={es.attachments.next}
                      disabled={open === photos.length - 1} onClick={() => setOpen(open + 1)}>
                <RiArrowRightSLine />
              </Button>
            </div>
          )}
        </DialogContent>
      </Dialog>
    </div>
  );
}
```

```ts
const QUALITY = 0.85;
const SHRINKABLE = new Set(["image/jpeg", "image/png", "image/webp", "image/heic", "image/heif"]);

type Named = { type: string; name: string };

export function isHeic(file: Named): boolean {
  return /^image\/hei[cf]$/.test(file.type) || /\.hei[cf]$/i.test(file.name);
}

/** GIF would lose its animation and SVG isn't a photo: those are never
 *  re-encoded, nor is anything that isn't an image. */
export function shouldShrink(file: Named): boolean {
  return SHRINKABLE.has(file.type) || (file.type === "" && isHeic(file));
}

export function fitWithin(w: number, h: number, max: number) {
  const scale = Math.min(1, max / Math.max(w, h));
  return { width: Math.round(w * scale), height: Math.round(h * scale) };
}

export function centerSquare(w: number, h: number) {
  const size = Math.min(w, h);
  return { sx: Math.round((w - size) / 2), sy: Math.round((h - size) / 2), size };
}

function jpegName(name: string): string {
  const dot = name.lastIndexOf(".");
  return `${dot > 0 ? name.slice(0, dot) : name}.jpg`;
}

async function encode(
  file: File,
  draw: (bmp: ImageBitmap) => { canvas: HTMLCanvasElement },
): Promise<File | null> {
  // "from-image" applies the EXIF orientation, so sideways photos come out
  // upright. Re-encoding also drops every bit of metadata, GPS included.
  const bmp = await createImageBitmap(file, { imageOrientation: "from-image" });
  try {
    const { canvas } = draw(bmp);
    const blob = await new Promise<Blob | null>((res) => canvas.toBlob(res, "image/jpeg", QUALITY));
    return blob ? new File([blob], jpegName(file.name), { type: "image/jpeg" }) : null;
  } finally {
    bmp.close();
  }
}

function canvasOf(width: number, height: number) {
  const canvas = document.createElement("canvas");
  canvas.width = width;
  canvas.height = height;
  const ctx = canvas.getContext("2d")!;
  // A transparent PNG would come out with a black background in JPEG.
  ctx.fillStyle = "#ffffff";
  ctx.fillRect(0, 0, width, height);
  return { canvas, ctx };
}

/** 2048 px on the long side, JPEG 0.85. Returns the original whenever it
 *  can't help: not a photo, undecodable here (HEIC on desktop Chrome), any
 *  failure, or a JPEG/PNG/WebP that would come out larger. A HEIC is always
 *  converted — Android can't show HEIC at all. */
export async function shrinkImage(file: File, max = 2048): Promise<File> {
  if (!shouldShrink(file)) return file;
  try {
    const out = await encode(file, (bmp) => {
      const { width, height } = fitWithin(bmp.width, bmp.height, max);
      const { canvas, ctx } = canvasOf(width, height);
      ctx.drawImage(bmp, 0, 0, width, height);
      return { canvas };
    });
    if (!out) return file;
    if (!isHeic(file) && out.size >= file.size) return file;
    return out;
  } catch {
    return file;
  }
}

/** Centre square, size × size, for the profile photo. */
export async function squareAvatar(file: File, size = 512): Promise<File> {
  try {
    const out = await encode(file, (bmp) => {
      const { sx, sy, size: side } = centerSquare(bmp.width, bmp.height);
      const target = Math.min(size, side);
      const { canvas, ctx } = canvasOf(target, target);
      ctx.drawImage(bmp, sx, sy, side, side, 0, 0, target, target);
      return { canvas };
    });
    return out ?? file;
  } catch {
    return file;
  }
}

export function prepareFiles(files: File[]): Promise<File[]> {
  return Promise.all(files.map((f) => shrinkImage(f)));
}
```

```tsx
    />
  ) : (

      className="flex items-center justify-center rounded-full bg-muted font-semibold"
      style={{ width: size, height: size }}
```

```tsx
          <Avatar author={user} size={96} />
        )}
        <input
          ref={input}
          type="file"
          accept="image/*"
          hidden
          onChange={async (e) => {
            const picked = e.target.files?.[0];
            e.target.value = "";
            if (!picked) return;
            const file = await squareAvatar(picked);
            setPreview({ file, url: URL.createObjectURL(file) });
          }}
        />
        {preview ? (
          <>
            <Button onClick={savePhoto} disabled={busy}>{es.perfil.savePhoto}</Button>
            <Button variant="outline" onClick={() => setPreview(null)} disabled={busy}>
              {es.perfil.cancel}
            </Button>
          </>
        ) : (
          <>
            <Button variant="outline" onClick={() => input.current?.click()} disabled={busy}>
              {es.perfil.changePhoto}
            </Button>
            {hasOwnPhoto && (
              <Button variant="ghost" onClick={removePhoto} disabled={busy}>
                {es.perfil.removePhoto}
              </Button>
            )}
          </>
        )}
      </section>

      <section className="flex flex-col gap-3">
        <Label htmlFor="bio">{es.perfil.bioLabel}</Label>
        <Textarea id="bio" value={bio} maxLength={500} onChange={(e) => setBio(e.target.value)} />
        <Button onClick={saveBio} disabled={busy || bio === user.bio}>{es.perfil.saveBio}</Button>
      </section>
    </div>
  );
}
```

Add `has_own_avatar: boolean;` to `interface User` in `frontend/src/lib/types.ts` (include `frontend/src/lib/types.ts` in the commit).
