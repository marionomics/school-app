# Racha — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A per-student daily streak raises the odds that a post's aura counts 2× or 3×; the roll happens once at publish, is stored, and the grade engine weights each post's auras by it.

**Architecture:** Pure streak functions in `app/services/streak.py` (dates → streak → level → odds → roll). `create_post` calls `maybe_roll`, which stores one `post_rolls` row per qualifying post. `grades.ledger_breakdown` counts like rows weighted by the liked post's multiplier before applying the unchanged concave curve. Per-class `points_config.streak_levels` holds the odds table, edited in Configurar. The frontend shows a streak chip in the top bar, a 2×/3× badge on cards, a toast at publish and the streak on profiles.

**Tech Stack:** FastAPI, SQLAlchemy, Alembic, pytest (CI on PostgreSQL); React + Vite + Tailwind, TanStack Query, vitest; shadcn `base-sera` on `@base-ui/react`; `@remixicon/react`.

**Spec:** `docs/superpowers/specs/2026-10-31-racha-design.md` — read it first.

## Global Constraints

- Grades are computed, never stored. The roll is an append-only `post_rolls` row written once at publish; never recomputed, updated or deleted by the app.
- The engine never sums like rows' `points`; it counts non-revoked `forum_like` rows weighted by the liked post's multiplier (1 if no roll), then applies `like_points` unchanged.
- Counting contribution: `active` post by a non-teacher with `len(content.strip()) >= 20` or at least one attachment (`MIN_CONTRIBUTION_CHARS = 20`).
- Streak: consecutive calendar dates in `settings.timezone` ("America/Mexico_City") ending today, or yesterday if today has none; computed from posts, never stored.
- Roll only when the author is `active` in `post.class_id`; teachers, ghost, polizón and posts with no class never roll. The streak used includes the post being published.
- Draw: `u < x3 → 3`, else `u < x3 + x2 → 2`, else `1`; the draw happens on the server.
- Default levels: `[{"from_days": 3, "x2": 0.15, "x3": 0.0}, {"from_days": 7, "x2": 0.2, "x3": 0.05}, {"from_days": 14, "x2": 0.25, "x3": 0.1}]`. Validation: `from_days >= 1` strictly increasing, `0 <= x2, x3`, `x2 + x3 <= 1`, at most 8 levels; all zeros allowed.
- `PostOut.multiplier` is 2 or 3 (else null), visible to everyone, null on deleted posts.
- UI: preset components only, icons from `@remixicon/react`, strings only in `frontend/src/strings/es.ts` (Spanish, tú), every name through `UserLink`, one control per line in forms, mobile first.
- Version: this block ships as **v0.2.23** (bump `frontend/package.json` and the root of `package-lock.json`; changelog heading carries it).
- Backend tests: `cd backend && .venv/bin/python -m pytest -q`. Frontend: `cd frontend && npx tsc -b && npx vitest run && npx eslint src && npm run build`. vitest has no `@` alias: modules imported by tests use relative imports.
- Implementers commit, never push.

## Review Focus

1. **Midnight in Mexico City vs UTC** — a post at 23:30 local (05:30 UTC next day) belongs to the local date. Pinned in Task 2.
2. **A deleted or vetoed post from yesterday** shortens today's streak (computed), but never changes a roll already stored. Pinned in Tasks 2 and 3.
3. **An unlike** drops the weighted count by that post's multiplier, not by 1. Pinned in Task 4.
4. **A class with all-zero levels** never rolls 2×/3× but still stores 1× rolls and still shows the streak. Pinned in Tasks 3 and 5.
5. **Malformed `streak_levels` from the client** (unsorted, x2+x3 > 1, negative, 9 levels) is rejected with 422, never stored. Pinned in Task 5.

```python
# backend/app/services/streak.py
"""Racha: the per-student daily streak and the 2×/3× roll (spec 2026-10-31).

Pure functions over dates and a level table, plus one query that collects the
dates a student contributed. The streak is computed, never stored; a roll is
stored once at publish (maybe_roll, Task 3).
"""
from datetime import date, datetime, timedelta, timezone
from decimal import Decimal
from typing import Optional
from zoneinfo import ZoneInfo

from sqlalchemy import func, or_
from sqlalchemy.orm import Session

from app.config import settings
from app.models import Post, User

MIN_CONTRIBUTION_CHARS = 20
TZ = ZoneInfo(settings.timezone)
# Far enough back for any semester; keeps the query bounded.
LOOKBACK_DAYS = 400


def is_contribution(content: str, has_files: bool) -> bool:
    return has_files or len((content or "").strip()) >= MIN_CONTRIBUTION_CHARS


def local_date(dt: datetime) -> date:
    """A naive datetime is UTC (SQLite returns naive)."""
    if dt.tzinfo is None:
        dt = dt.replace(tzinfo=timezone.utc)
    return dt.astimezone(TZ).date()


def local_today(now: Optional[datetime] = None) -> date:
    return local_date(now or datetime.now(timezone.utc))


def contribution_dates(db: Session, user_id: int) -> set:
    """Local dates on which this student made a counting contribution."""
    since = datetime.now(timezone.utc) - timedelta(days=LOOKBACK_DAYS)
    rows = (db.query(Post.created_at)
            .join(User, User.id == Post.author_id)
            .filter(Post.author_id == user_id,
                    User.role != "teacher",
                    Post.status == "active",
                    Post.created_at >= since,
                    or_(func.length(func.trim(Post.content)) >= MIN_CONTRIBUTION_CHARS,
                        Post.attachments.any()))
            .all())
    return {local_date(at) for (at,) in rows}


def today_done(dates: set, today: date) -> bool:
    return today in dates


def streak_days(dates: set, today: date) -> int:
    """Consecutive days ending today — or yesterday, while today is still open."""
    d = today if today in dates else today - timedelta(days=1)
    n = 0
    while d in dates:
        n += 1
        d -= timedelta(days=1)
    return n


def level_for(days: int, levels: list) -> Optional[dict]:
    found = None
    for lvl in sorted(levels, key=lambda l: l["from_days"]):
        if lvl["from_days"] <= days:
            found = lvl
    return found


def odds(days: int, levels: list) -> tuple:
    lvl = level_for(days, levels)
    if lvl is None:
        return Decimal("0"), Decimal("0")
    return Decimal(str(lvl["x2"])), Decimal(str(lvl["x3"]))


def next_level_at(days: int, levels: list) -> Optional[int]:
    later = [l["from_days"] for l in levels if l["from_days"] > days]
    return min(later) if later else None


def roll(x2: Decimal, x3: Decimal, u: float) -> int:
    """One uniform draw u in [0, 1): 3× first, then 2×, else 1×."""
    u = Decimal(str(u))
    if u < x3:
        return 3
    if u < x3 + x2:
        return 2
    return 1
```

```python
def _draw() -> float:
    """The server's uniform draw in [0, 1). Tests monkeypatch this."""
    return random.random()


def maybe_roll(db: Session, post: Post, author: User, has_files: bool) -> Optional["PostRoll"]:
    """Roll a freshly flushed post once, if it qualifies (spec §1). The
    streak includes this post: the first post of the day counts the day."""
    if author.role == "teacher" or post.class_id is None:
        return None
    if not is_contribution(post.content, has_files):
        return None
    active = (db.query(Enrollment)
              .filter(Enrollment.user_id == author.id,
                      Enrollment.class_id == post.class_id,
                      Enrollment.status == "active").first())
    if active is None:
        return None
    db.flush()   # the attachments added for this post must be visible
    days = streak_days(contribution_dates(db, author.id), local_today())
    x2, x3 = odds(days, get_config(db, post.class_id).streak_levels)
    r = PostRoll(post_id=post.id, multiplier=roll(x2, x3, _draw()),
                 streak_days=days, x2=x2, x3=x3)
    db.add(r)
    return r
```
