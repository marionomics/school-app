Teacher Dashboard: Navigation Structure

The current 7-tab layout feels overloaded. Here are 3 ways to consolidate it — which direction feels right?

Current — 7 tabs
Vista General Lista de Alumnos Asistencia Exámenes Participación Retos Justificaciones 3

Scrolls horizontally on small screens. Hard to find things. Badge for justifications easy to miss.

A

Merge by topic — 5 tabs

Vista General Alumnos Asistencia + Justif. Evaluaciones Participación

▸ Asistencia & Justificaciones merged (justifications are about absences, same context)

▸ Evaluaciones = Exámenes + Retos in one tab, filterable by type

Pros

  • Least disruptive — familiar structure
  • Justifications found naturally next to attendance
  • Grading all in one place

Cons

  • Still 5 tabs — moderate improvement
  • Evaluaciones tab gets busier
B

Time-based grouping — 4 tabs

Hoy new Alumnos Evaluaciones Historial

▸ "Hoy" = attendance + participation + pending alerts, all on one screen — what you need every class day

▸ "Evaluaciones" = Exámenes + Retos + grade categories

▸ "Historial" = Asistencia (calendar view) + Justificaciones

Pros

  • "Hoy" tab matches real teaching workflow
  • Only 4 tabs — much cleaner
  • Attendance + participation live together (both daily actions)

Cons

  • Bigger conceptual shift — "Hoy" is new mental model
  • Historial tab could get complex
C

Minimal + side panels — 3 tabs

Resumen Alumnos Actividad

▸ "Resumen" = quick actions, at-risk, stats (current Vista General)

▸ "Alumnos" = roster with click-to-expand per-student drawer (grades, attendance, submissions)

▸ "Actividad" = scrollable page with anchored sections: Asistencia / Participación / Retos / Exámenes / Justificaciones — no sub-tabs, just scroll

Pros

  • Fewest tabs — cleanest chrome
  • "Actividad" section anchors replace tabs with scroll
  • Student detail in side drawer reduces navigation jumps

Cons

  • "Actividad" page very long — requires good anchor nav
  • Biggest rewrite of the three
